{\LARGE\bfseries VoyagerMapper quick start}\hfill{\small v0.1.1}

\vspace{2pt}
Install VoyagerMapper on Windows, then make a map file for the Trail Tech
Voyager Pro in four steps. The default settings make a file that loads on the
device. You do not have to change them.

\setcounter{section}{-1}
\section{Install and start the app}

You do this once. You need an internet connection. If you prefer an installer,
download \texttt{voymap-setup-<version>.exe} from the Releases page at
\url{https://github.com/GnomeTek/VoyagerMapper/releases} and skip to step 0.4.

\subsection*{0.1 Install Python}
\begin{enumerate}
  \item Open \url{https://www.python.org/downloads/} and download Python for
        Windows (3.10 or newer).
  \item Start the installer.
  \item On the first screen, check \btn{Add python.exe to PATH}.
  \item Click \btn{Install Now} and wait for the installer to finish.
\end{enumerate}
If Python is already installed, skip this step.

\subsection*{0.2 Download the source}
\begin{enumerate}
  \item Open \url{https://github.com/GnomeTek/VoyagerMapper}.
  \item Click the green \btn{Code} button.
  \item Click \btn{Download ZIP}.
  \item Open the downloaded file \texttt{VoyagerMapper-main.zip} and extract it
        to a folder you keep, for example
        \texttt{C:\textbackslash Users\textbackslash <you>\textbackslash Documents\textbackslash VoyagerMapper}.
\end{enumerate}
The folder must contain \texttt{setup.bat}, \texttt{run\_gui.bat}, and
\texttt{pyproject.toml}. If you use git, you can instead run
\texttt{git clone https://github.com/GnomeTek/VoyagerMapper.git}.

\subsection*{0.3 Run setup}
\begin{enumerate}
  \item Open the folder from step 0.2.
  \item Double-click \btn{setup.bat}.
\end{enumerate}
A command window opens. The script makes a Python environment in a
\texttt{.venv} subfolder, installs the app and its libraries (about 200\,MB,
most of it the Qt map view), and runs the self-test. This takes a few minutes.
The last lines you see are:
\begin{verbatim}
26 passed in ...s

Setup complete. Double-click run_gui.bat to start voymap.
Press any key to continue . . .
\end{verbatim}
Press a key to close the window. If the window shows \texttt{Setup failed},
read the lines above it. The usual cause is that Python is not on the PATH:
repeat step 0.1 and make sure the \btn{Add python.exe to PATH} box is checked.

\needspace{8\baselineskip}
\subsection*{0.4 Start the app}
\begin{enumerate}
  \item Double-click \btn{run\_gui.bat} in the same folder.
  \item Wait for the window with the map to open.
\end{enumerate}
If you used the installer, start \btn{voymap} from the Start menu instead.
The map starts on northern Arizona. Pan and zoom to your riding area. A command
window stays open behind the app while it runs. Close the app to close it.

\section{Select the map and set the opacity}

\begin{center}
\includegraphics[width=0.7\textwidth]{qs1_layers.png}
\end{center}

\begin{enumerate}
  \item In the \btn{Layers} panel, check the box next to the map you want \n{1}.
        Check one base map, for example \emph{OpenTopoMap} or \emph{USGS Topo}.
        You can also check overlays, for example \emph{USFS MVUM (labeled)}.
  \item Drag the slider at the right of the row to set the opacity \n{2}.
        The map view shows the result at once.
\end{enumerate}

\begin{center}
\includegraphics[width=0.8\textwidth]{qs2_opacity.png}
\end{center}

The slider also sets the opacity in the exported file. For a base map, keep the
slider at 100\,\%. Use a lower value for an overlay that hides the base map.

\clearpage
\section{Draw the export area}

\begin{center}
\includegraphics[width=0.95\textwidth]{qs3_area.png}
\end{center}

\begin{enumerate}
  \item In the \btn{Export to Voyager Pro} panel, click \btn{Draw export rectangle} \n{3}.
  \item On the map, press the mouse button at one corner of the area \n{4}.
  \item Hold the button, drag to the opposite corner, and release \n{5}.
\end{enumerate}

The app shows the area as a dashed magenta rectangle. The line under the buttons
shows the tile count and the approximate file size \n{6}. A thin dotted outline
shows the area snapped to the tile grid. That is the area the app exports.

To change the area, click \btn{Draw export rectangle} again and draw a new
rectangle. \btn{Clear} removes the area.

\clearpage
\section{Export the map}

\begin{center}
\includegraphics[width=0.62\textwidth]{qs4_export.png}
\end{center}

\begin{enumerate}
  \item Type a name in \btn{Map name} \n{7}. The Voyager Pro shows this name in
        its list of custom maps.
  \item Keep the \btn{Zoom levels} at the default, 8 to 14 \n{8}. More zoom levels
        make a larger file. Each level above 14 makes the file four times larger.
  \item Click \btn{Export MBTiles\ldots} \n{9}.
  \item In the file dialog, choose where to save the \texttt{.mbtiles} file and
        click \btn{Save}.
\end{enumerate}

\begin{center}
\includegraphics[width=0.62\textwidth]{qs5_progress.png}
\end{center}

The top bar shows the overall progress \n{10}. The bottom bar shows the current
step. The export downloads the tiles for each layer, then writes the file. A
message box opens when the export is complete. \btn{Cancel} stops the export.

\needspace{14\baselineskip}
\section{Load the map on the Voyager Pro}

\begin{enumerate}
  \item Copy the \texttt{.mbtiles} file to the microSD card of the Voyager Pro.
  \item Put the card in the Voyager Pro.
  \item On the device, go to the map screen.
  \item Tap \btn{CUSTOM MAPS}.
  \item Tap \btn{IMPORT A NEW FILE} and select the file.
\end{enumerate}

The device processes the file and shows a message when it is done.

\begin{tcolorbox}[colback=gray!6, colframe=gray!50, title=Tips]
\begin{itemize}
  \item The app keeps the downloaded tiles in a cache. A second export of the
        same area, for example a night version, does not download the tiles again.
  \item Select \btn{Night} in \btn{Theme} to make a dark map. Check
        \btn{export a day + night pair} to make both files in one export.
  \item \btn{File $\rightarrow$ Save project} saves the area, the layers, and the
        export settings, so you can make the same map again later.
\end{itemize}
\end{tcolorbox}
